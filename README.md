# PyTech Level 2 – Py-Pioneers

This repository contains our submissions for the PyTech Arena Level-2 Hackathon.

Team Name: Py-Pioneers

Projects Included:

1. Pass/Fail Predictor
A Machine Learning project that predicts whether a student will PASS or FAIL based on their academic scores using Logistic Regression.

2. Sales Summary Dashboard
A Data Analysis project that analyzes sales data and generates summary reports and sales charts.

Technologies Used:
Python
Pandas
Scikit-learn
Matplotlib

How to Run:

Pass-Fail Predictor:
python main.py

Sales Summary Dashboard:
python main.py

Both projects are available in their respective folders with dataset, source code, and output files.
